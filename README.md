# BetOnGame Partners Website

Files:
- `index.html` — page structure
- `css/style.css` — complete design/theme
- `js/script.js` — tracking-link buttons, mobile menu and cookie button
- `assets/header-logo.png` — the exact header/logo image supplied by you

## GitHub Pages

1. Create a GitHub repository.
2. Upload the complete `betongame-partners` folder contents.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save.

All Register/Login/Start Earning buttons already use the supplied tracking link.
